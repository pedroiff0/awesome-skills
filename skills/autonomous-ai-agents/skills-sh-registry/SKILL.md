# Skills.sh Registry & Ecosystem Discovery

> **Attribution**: Originating from Vercel Labs (skills.sh open agent directory).

This skill provides operational patterns for searching, evaluating, and installing skills from the global skills.sh catalog into local multi-agent environments.

---

## Usage Patterns

```bash
# Query skills via npx skills
npx skills add <owner/repo>

# List installed skills across environments
awesomeskills list
```
