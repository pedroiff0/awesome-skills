# MCP Server: context-mode

Context compression, indexed AST searches, and token-saving operations for large repositories.

## Configuration (Claude Desktop / Cursor / Antigravity)

```json
{
  "mcpServers": {
    "context-mode": {
      "command": "npx",
      "args": ["-y", "@context-mode/mcp-server"]
    }
  }
}
```
