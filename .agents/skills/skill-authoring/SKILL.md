# Skill Authoring — Awesome Skills

Instruções para criação de novas skills:

1. **Estrutura de Arquivos:**
   - Criar diretório em `skills/<nome-da-skill>/`.
   - Adicionar `SKILL.md` com cabeçalho YAML frontmatter e seções de instruções claras.
2. **Validação:**
   - Rodar `make validate` para assegurar conformidade com o parser do CI.
